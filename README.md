# <img width="30" height="30" alt="grif2" src="https://github.com/user-attachments/assets/11c4681b-152e-402f-a6d0-6371188cd60d" /> GRIF
Gost and RDF Information Formatter

Программное обеспечение GRIF предназначено для редактирования и формирования текстовых версий документов и проектов изменений как для стандартов серии ГОСТ Р 58651, так и для профилей информационного обмена.

## Установка
Для установки ПО необходимо загрузить соотвествующий дистрибутив на рабочий ПК и расположить его в отдельной папке. Запуск программы происходит путем исполнения файла GRIF.exe, расположенного в папке дистрибутива.

## Настройка
> Формирование текстовых версий ГОСТ производится на основе файла стандартной канонической модели в формате *.xmi, который загружается через ПО RAVEN.

Для создания текстовой версии необходим текстовый шаблон в формате *.docx и конфигурационный файл в формате *.json

### Конфигурационный файл
Состав и конфигурация документов серии ГОСТ Р 58651 определяется в соответствующем конфигурационном файле в папке дистрибутива **\Конфигурационные файлы\Профили модели.json** и имеет следующий формат:

```
{
    "Items": [
        {
            "Tag": "2",
            "Name": "ГОСТ Р 58651.2-2019",
            "Tables": [
                {
                    "BookmarkName": "АбстрКлассыИМ",
                    "DisplayName": "Абстрактные классы базисного профиля информационной модели",
                    "Tag": null,
                    "DataType": "Абстрактные классы"
                },
        ...
        ]
        },
    ...
    ]
}
```

Где в поле Tag указывается номер ГОСТа, в поле Name - наименование. Каждая из таблиц в списке Tables соответствует таблице в текстовой версии ГОСТ (абстрактные классы, основные классы и т.д.). Таблица характеризуется наименованием закладки BookmarkName в подготовленном текстовом шаблоне (см. описание далее), отображаемом наименовании в интерфейсе приложения DisplayName, тэгом Tag (который определяет принадлежность данных таблицы, например, к приложению документа) и типом данных DataTypе.

**Возможные типы данных:**
* Абстрактные классы;
* Основные классы;
* Атрибуты;
* Ассоциации;
* Структурные классы;
* Атрибуты структурных классов;
* Справочные классы;
* Атрибуты справочных классов.

**Примеры тэгов** (должны соответствовать наименованию тэга basicProfileExtension в файле канонической модели в формате XMI) для ГОСТ Р 58651.2:
* measurement;
* electricityMetering;
* DCLine.
  
### Текстовый шаблон
Текстовый шаблон создается пользователем и должен располагаться в папке \Шаблоны Профили модели\Наименование ГОСТ. Например, Шаблоны Профили модели\ГОСТ Р 58651.2-2019. Наименование указывается в поле Name конфигурационного файла. Наименование самого файла шаблона может быть произвольным.

В шаблоне должны отсутствовать таблицы классов, ассоциаций и атрибутов (при этом наименования таблиц необходимо сохранить). Шаблон необходимо наполнить закладками (в Microsoft Word кнопка находится по пути Вставка - Закладка, в Р7 по пути Ссылки - Закладка):
* закладками разделов (любое название закладки)
* закладками таблиц (название закладки должно соответствовать полю BookmarkName для соответствующей таблицы в конфигурационном файле)

## Редактирование и формирования ГОСТ
Для редактирования открывается окно предварительного просмотра:

<img width="1923" height="1042" alt="интерфейс_гост" src="https://github.com/user-attachments/assets/9b166145-43fe-4d0f-8d3f-6d85689815e6" />

Элементы интерфейса разделены на следующие области:
* 1 — Кнопки работы с файлом:
  * Загрузить шаблон — открывает окно выбора нового шаблона из соответствующей папки ГОСТ
  * Сохранить шаблон — сохраняет текущий загруженный документ со всеми изменениями в качестве нового шаблона
  * Выгрузить изменения — выгружает проект изменений документа в папку \Изменения текстовых версий Профилей модели
  * Выгрузить документ — выгружает обновленный документ в папку \Текстовые версии Профилей модели 
* 2 — Информационная область: 
  * Кнопка выхода из режима редактирования
  * Наименование ГОСТ
  * Данные о загруженном шаблоне
* 3 — Разделитель структурной части
* 4 — Текстовый фрагмент, сформированный из набора текстовых элементов между двумя закладками шаблона
* 5 — Область редактирования текстового фрагмента:
  * Кнопка редактирования файла — открывает экземпляр приложения для редактирования текстового фрагмента
  * Кнопка сброса изменений — возвращает файл в исходное состояние
* 6 — Область управления базой данных:
  * Кнопка создания новой версии документа — сохраняет данные о состоянии таблиц ГОСТа (используется при утверждении новой версии ГОСТ)
  * Кнопка восстановления предыдущей версии — удаляет в БД записи о последнем сохраненном состоянии таблиц ГОСТа

## Редактирование и формирования Профиля информационного обмена
Элементы интерфейса аналогичны окну предварительного просмотра ГОСТ за исключением того, что в области кнопок работы с файлом отсутствуют кнопки Сохранения и Загрузки шаблона. Также особенностью отображения таблиц является то, что появляется строка с пометкой родительского класса, в котором впервые определен атрибут или ассоциация.

Текстовая версия профиля обмена и проект изменений профиля обмена сохраняются соответственно в папках \Текстовые версии Профилей обмена и \Изменения текстовых версий Профилей обмена
